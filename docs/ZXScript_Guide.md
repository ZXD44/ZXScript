# คู่มือการใช้งาน ZXScript ฉบับสมบูรณ์ (โดย zxd44 / ZirconX)
*Roblox Studio AI Agent Bridge with Native Bloxstrap & Studio MCP Support*

---

## 1. สรุปปัญหาที่ตรวจพบและการแก้ไขในระดับโค้ด (Root Cause & Patched)

จากการวิเคราะห์โค้ดเชิงลึกของ ZeroScript เดิม ทีมพัฒนาพบจุดบกพร่องสำคัญ 4 จุด และได้ทำการแก้ไขในระดับ Source Code ของ **ZXScript** แล้ว:

| ลำดับ | ปัญหาเดิมที่พบ | จุดบกพร่องในโค้ดเดิม | การแก้ไขใน ZXScript (โดย zxd44) |
|---|---|---|---|
| **1** | **บัญชี AI โดนแบน / ติด Rate Limit** | ใน `core/main.js` ตั้งค่า `HUMANIZE_SEND = false` ทำให้ระบบส่งคำสั่งกลับเว็บ AI ทันทีด้วยความเร็วบ็อต (0ms) จน Cloudflare/DeepSeek ตรวจจับ | **แก้ไขแล้ว:** เปิด `HUMANIZE_SEND = true` พร้อมระบบสุ่มดีเลย์เลียนแบบมนุษย์ `1000 - 2200ms` เพื่อบายพาสระบบตรวจจับบ็อตอย่างสมบูรณ์ |
| **2** | **AI เลิกใช้คำสั่ง ตอบเป็นโค้ดธรรมดา** | ใน `core/main.js` มีบั๊กตรรกะในฟังก์ชัน `sysResendDue()` ที่ไม่ยอมส่ง System Prompt ซ้ำบน DeepSeek/Qwen และตั้งเตือนความจำคำสั่งห่างเกินไป (`REMIND_TOOLS_EVERY = 20`) | **แก้ไขแล้ว:** ปรับให้รีเฟรชคำสั่งทุกๆ **8 Tool Calls** และส่งทบทวน System Prompt ทุกๆ **6-8 รอบ** บนทุกโมเดล AI ป้องกัน AI ลืมคำสั่ง 100% |
| **3** | **ไฟสถานะค้างสีเหลือง (ไม่พบ StudioMCP)** | ใน `launch_studio_mcp.py` มองหาเฉพาะโฟลเดอร์ Roblox ปกติ แต่ผู้ใช้ส่วนใหญ่ติดตั้งผ่าน **Bloxstrap** | **แก้ไขแล้ว:** เพิ่มระบบ Auto-Detection ตรวจจับโฟลเดอร์ Bloxstrap และอ่าน `mcp.bat` อัตโนมัติ เชื่อมต่อครบ 28 Tools ทันที |
| **4** | **โปรเซสซอมบี้พอร์ต 17613 และ 13469** | ปิดโปรแกรมแล้ว `StudioMCP.exe` เก่ายังค้างฟังพอร์ตอยู่ ทำให้รันใหม่ไม่ผ่าน | **แก้ไขแล้ว:** ระบบ Bridge ตรวจจับและล้าง Process ซอมบี้ที่ตกค้างให้อัตโนมัติก่อน Bind พอร์ตใหม่ |

## 2. ขั้นตอนการติดตั้งและเริ่มใช้งาน (Step-by-Step)

### ขั้นตอนที่ 1: ติดตั้ง Browser Extension ลงใน Chrome หรือ Edge
1. เปิดเบราว์เซอร์ **Google Chrome** หรือ **Microsoft Edge**
2. ไปที่หน้าจัดการส่วนขยาย:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. เปิดสวิตช์ **Developer mode (โหมดนักพัฒนา)** ที่มุมขวาบน
4. กดปุ่ม **Load unpacked (โหลดส่วนขยายที่คลายการบีบอัดแล้ว)**
5. เลือกโฟลเดอร์:
   ```text
   C:\Users\ZirconX\Documents\New folder\zxscript-extension
   ```

### ขั้นตอนที่ 2: เปิดแมพใน Roblox Studio & เปิดใช้งาน MCP
1. เปิด **Roblox Studio** และเข้าแมพ (Place) ที่ต้องการสร้างเกม (ต้องโหลดเข้าแมพเรียบร้อยแล้ว ห้ามค้างหน้าเมนูหลัก)
2. บนแถบเมนูด้านบน กดปุ่ม **Assistant AI**
3. ที่มุมขวาบนของหน้าต่าง Assistant กดปุ่ม **`...` (จุดสามจุด)**
4. เลือกเมนู **Manage MCP Servers**
5. ติ๊กเปิด **Enable Studio as MCP Server** (เปิดแมพค้างไว้ตลอดการทำงาน)

### ขั้นตอนที่ 3: รัน Bridge Server
1. ดับเบิลคลิกไฟล์ [`start.bat`](file:///C:/Users/ZirconX/Documents/New%20folder/start.bat)
2. สังเกตหน้าต่างสีดำจะแสดงสถานะ:
   - `=== ZXScript Bridge - by ZXD44 ===`
   - `[roblox] MCP server up (28 tools advertised)`
   - `listening on ws://127.0.0.1:17613`
3. **เปิดหน้าต่างสีดำนี้ย่อทิ้งไว้ตลอดเวลาที่สั่งงาน AI**

### ขั้นตอนที่ 4: เชื่อมต่อหน้าเว็บ AI และเริ่มทำงาน
1. เข้าเว็บ AI ที่ต้องการ:
   - `chat.deepseek.com` (แนะนำที่สุดสำหรับการเขียนโค้ด)
   - `chat.qwen.ai` (สำรองยอดเยี่ยม ข้อจำกัดบ็อตต่ำมาก)
   - `chatgpt.com`
2. ดูแถบ **ZXScript Bar** เหนือกล่องพิมพ์ข้อความ:
   - 🟢 **สีเขียว:** ระบบพร้อมทำงาน 100% (Bridge ทำงาน + แมพใน Studio เปิดพร้อม MCP)
   - 🟡 **สีเหลือง:** Bridge ทำงานแล้ว แต่ยังไม่โหลดเข้าแมพใน Studio หรือลืมเปิด MCP
   - ⚪ **สีเทา:** ยังไม่ได้รัน `start.bat`
3. เมื่อขึ้นจุด **สีเขียว** ให้กด **Start session** บนแถบ ZXScript จากนั้นส่ง Prompt จากหัวข้อที่ 4 ด้านล่าง

## 3. วิธีป้องกันปัญหาเพิ่มเติมและข้อควรระวัง (Best Practices)

1. **การป้องกันบัญชีโดนแบน (Anti-Ban Rules):**
   - แม้ตัว Extension จะมีระบบ Humanized Jitter Delay แล้ว แต่**ห้ามสั่งงานใหญ่ในพรอมต์เดียว** (เช่น *"สร้างเกม Blox Fruits ให้เสร็จทั้งเกม"*) เพราะจะทำให้เกิด Loop เรียกเครื่องมือ 20-30 ครั้งติดกัน
   - ให้สั่งงานแบบ **"โมดูลย่อย" (Sub-system)** ทีละ 1 ระบบ เช่น ระบบ Leaderstats -> ระบบเก็บเหรียญ -> ระบบร้านค้า
   - แนะนำให้ใช้อีเมลสำรองในการล็อกอินเว็บ AI เพื่อความปลอดภัย

2. **การจัดการเมื่อคุยยาวเกินไป (Context Overflow):**
   - หากแชทมีความยาวเกิน 15-20 ข้อความ ให้เปิด **New Chat** ใหม่เสมอ
   - ก่อนเปิด New Chat ให้ใช้ **Prompt ชุดที่ 5 (บันทึก Project Memory)** เพื่อให้ AI จดจำโครงสร้างเกมลงใน `game.ServerStorage.ZXScript.Memory` เมื่อเปิดแชทใหม่ AI ตัวถัดไปจะอ่าน Memory นี้และทำงานต่อได้ทันทีโดยที่งานไม่สูญหาย

3. **กรณีแถบ ZXScript ไม่แสดงบนหน้าเว็บ AI:**
   - ปิดฟังก์ชัน Google Translate / แปลภาษาอัตโนมัติของเบราว์เซอร์ในแท็บนั้น
   - ปิดหรือเพิ่มข้อยกเว้นในส่วนขยาย AdBlock สำหรับเว็บ AI
   - กด `Ctrl + F5` เพื่อ Hard Refresh หน้าเว็บ

### ชุดที่ 1: Prompt เริ่มต้นโปรเจกต์ใหม่ (Initial Project Architecture)
> **ใช้เมื่อ:** กด Start Session ในแชทใหม่ เพื่อกำหนดบทบาท วางโครงสร้างโฟลเดอร์ และบล็อกไม่ให้ AI รัน Loop มั่ว

```text
คุณคือ Senior Roblox Luau Developer ที่ควบคุม Roblox Studio ผ่านเครื่องมือ MCP ของ ZXScript
ในการทำงานร่วมกับฉัน ให้ยึดถือกฎเหล็ก 5 ข้อนี้อย่างเคร่งครัด:
1. สำรวจก่อนลงมือเสมอ: ก่อนสร้างหรือแก้ไข Instance ใดๆ ให้ใช้เครื่องมือ search_game_tree หรือ inspect_instance ตรวจสอบโครงสร้างใน Workspace, ServerScriptService, และ ReplicatedStorage ก่อนเสมอ ห้ามเดา Path เอาเองเด็ดขาด
2. จำกัดรอบการทำงาน (ไม่เกิน 3-5 tool calls ต่อ 1 คำตอบ): เมื่อทำระบบย่อยเสร็จ 1 ส่วน ให้สรุปผลลัพธ์สั้นๆ แล้วหยุดรอคำสั่งถัดไปจากฉันทันที เพื่อป้องกันระบบค้างและป้องกันการโดนตรวจจับบ็อต
3. มาตรฐานโค้ด Luau สมัยใหม่: ใช้ task.wait(), task.spawn(), เช็ก nil ด้วย FindFirstChild หรือ WaitForChild(name, 5) ที่มี Timeout เสมอ และห้ามเขียน Infinite Loop เด็ดขาด
4. ใช้ execute_luau ผ่านบล็อก ###LUA### เท่านั้น: ห้ามห่อ Lua code ใน JSON string
5. บันทึกสถาปัตยกรรมลง Memory: เมื่อวางระบบหลักเสร็จ ให้จดบันทึกไว้ใน game.ServerStorage.ZXScript.Memory เสมอ

ภารกิจแรกของคุณ (Step 1):
ตรวจสอบโครงสร้างปัจจุบันในแมพของฉันว่ามีอะไรอยู่บ้าง จากนั้นเตรียมสร้างโครงสร้างโฟลเดอร์มาตรฐานใน ServerScriptService, ReplicatedStorage และ StarterGui สำหรับเกมแนว [ระบุแนวเกมของคุณ เช่น Simulator / Obby / Tower Defense] เมื่อสร้างเสร็จให้สรุปและหยุดรอคำสั่งต่อไป
```

### ชุดที่ 2: Prompt สั่งสร้างระบบเกมทีละส่วน (Step-by-Step Feature Implementation)
> **ใช้เมื่อ:** ต้องการสร้างฟังก์ชันหรือระบบใหม่ โดยไม่ให้กระทบหรือลบโค้ดเดิมที่มีอยู่

```text
เรากำลังจะสร้างระบบ: [ระบุชื่อระบบ เช่น ระบบสถิติผู้เล่น Leaderstats / ระบบเก็บเหรียญดรอปในฉาก / ระบบอาวุธดาบ]
ให้ทำตามลำดับขั้นตอนดังนี้อย่างรอบคอบ:
Step 1 (Audit): ตรวจสอบใน ReplicatedStorage และ ServerScriptService ว่ามี RemoteEvent หรือ Script เดิมที่เกี่ยวข้องอยู่แล้วหรือไม่
Step 2 (Instances): สร้าง Object / Part / UI ที่จำเป็น พร้อมกำหนด Properties (Anchored, CanCollide, Size, Color) ให้ถูกต้อง
Step 3 (Scripting): เขียนหรือแก้ไข Script/LocalScript โดยใส่ print("[Debug]") ในฟังก์ชันสำคัญเพื่อใช้ตรวจสอบการทำงาน
Step 4 (Validation): ตรวจสอบว่าไม่มี Syntax Error จากนั้นแจ้งสรุปว่าสร้างไฟล์อะไรไว้ที่ตำแหน่งใดบ้าง แล้วหยุดรอให้ฉันเข้าไปทดสอบใน Studio
```

### ชุดที่ 3: Prompt วินิจฉัยและแก้บั๊กอัตโนมัติ (Auto-Debug & Fix Prompt)
> **ใช้เมื่อ:** กดทดสอบใน Studio แล้วมีตัวหนังสือสีแดงแจ้ง Error ใน Output หรือระบบไม่ทำงานตามที่คาดหวัง

```text
ระบบ [ระบุชื่อระบบที่มีปัญหา] ยังทำงานไม่ถูกต้อง
อาการที่พบ: [อธิบายอาการ เช่น มี Error สีแดงขึ้นว่า 'Infinite yield possible on ...' หรือคลิกปุ่มแล้วเงินไม่ขึ้น]

ช่วยดำเนินการดีบักตามลำดับขั้นตอนนี้:
1. ใช้เครื่องมือ script_read เปิดอ่านโค้ดในสคริปต์ที่เกี่ยวข้องทั้งหมดเพื่อหาจุดผิดพลาด เช่น การสะกดชื่อ Instance ไม่ตรงกับใน Explorer หรือการเข้าถึงตัวแปรที่เป็น nil
2. ตรวจสอบ Hierarchy จริงในเกมว่า Object อยู่ตาม Path ที่โค้ดอ้างอิงจริงหรือไม่
3. แก้ไขโค้ดโดยเพิ่มการป้องกันข้อผิดพลาด (เช่น ใช้ pcall หรือ FindFirstChild พร้อม warn แจ้งเตือน)
4. สรุปสาเหตุของบั๊กและอธิบายจุดที่เพิ่งแก้ไขให้ฉันทราบสั้นๆ
```

### ชุดที่ 4: Prompt "ดึงสติ AI" (Emergency Wakeup Prompt)

```text
หยุดเดี๋ยวนี้! คุณกำลังพิมพ์โค้ดธรรมดาลงในแชทโดยไม่เรียกใช้เครื่องมือของ ZXScript
คุณมีสิทธิ์เข้าถึงและควบคุม Roblox Studio ของฉันโดยตรงผ่าน MCP Tools อยู่แล้ว กรุณาอย่าส่งโค้ดมาให้ฉันก๊อปปี้ไปวางเอง ให้คุณเรียกใช้เครื่องมือคำสั่ง (เช่น execute_luau ในบล็อก ###LUA### หรือ multi_edit) เพื่อสร้างและแก้ไขไฟล์ลงใน Roblox Studio ให้ฉันโดยตรงเดี๋ยวนี้!
```

เมื่อเขียนลง Memory เรียบร้อยแล้วให้แจ้งฉัน เพื่อให้ฉันเริ่ม New Chat ได้อย่างต่อเนื่อง

### ชุดที่ 6: Prompt บังคับ Caveman Mode (ประหยัด Token สูงสุด / Zero Fluff)
> **ใช้เมื่อ:** ต้องการให้ AI ตอบสั้นกระชับที่สุด ตัดคำทักทาย คำอธิบายเวิ่นเว้อ และประหยัดโควตา Token บนเว็บ AI สูงสุด

```text
เปิดใช้งาน Caveman Mode ในการตอบทุกครั้งนับจากนี้:
1. Zero Fluff: ตัดคำทักทาย คำนำ คำลงท้าย คำขอโทษ และบทสนทนาฟุ่มเฟือยทั้งหมด (ห้ามพูดคำว่า "ยินดีครับ", "แน่นอน", "นี่คือสิ่งที่คุณขอ")
2. Direct & Terse: ตอบเฉพาะข้อเท็จจริงแบบสั้นกระชับ ตรงประเด็นความหนาแน่นสูง
3. Tool-First: เน้นเรียกใช้เครื่องมือ MCP Tool ใน Roblox Studio โดยตรงทันที ไม่ต้องพิมพ์โค้ดมาให้อ่านซ้ำ
4. Token Efficiency: แก้ไขโค้ดแบบเจาะจงจุด (Surgical Edits) เพื่อประหยัด Token และป้องกัน Context หลุด
```
