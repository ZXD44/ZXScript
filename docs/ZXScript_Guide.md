## 1. จุดเด่นและระบบความปลอดภัย

1. **ระบบเลิกทำผ่าน Studio (ChangeHistoryService):** ทุกคำสั่งที่ AI สั่งรันใน Studio จะถูกบันทึกลงในประวัติการแก้ไข สามารถกด `Ctrl + Z` ใน Studio เพื่อเลิกทำได้ทันที หากสคริปต์ทำงานผิดพลาด ระบบจะย้อนคืนสถานะให้อัตโนมัติ
2. **ระบบป้องกันการระงับบัญชี (Anti-Ban Jitter):** หน่วงเวลาสุ่ม `1000 - 2200ms` เลียนแบบการพิมพ์ของมนุษย์ เพื่อป้องกันการตรวจจับจากระบบ Cloudflare และเว็บผู้ให้บริการ AI
3. **ตัดทอนข้อมูลโครงสร้างเกม (Smart Game Tree Pruning):** คัดกรอง Service ภายในที่ไม่จำเป็นออก (`CorePackages`, `CoreGui`) ช่วยประหยัด Token ได้ 60–80%
4. **แปลงโค้ดเป็น Luau ยุคใหม่ (Auto-Luau Modernizer):** ปรับแก้ฟังก์ชันเก่า (`wait`, `spawn`, `delay`) เป็น `task.wait`, `task.spawn`, `task.delay` อัตโนมัติในระดับ Bridge
5. **ระบบทำงานเบื้องหลัง (Headless Native Host):** Bridge ทำงานในเบื้องหลังโดยไม่ต้องเปิดหน้าต่าง CMD ภายนอก พร้อมระบบแสดงผล Log สดภายในส่วนขยาย
6. **ตรวจจับ Bloxstrap และ Studio อัตโนมัติ:** ตรวจหาไฟล์ `StudioMCP.exe` ในเครื่องโดยอัตโนมัติ พร้อมรองรับเครื่องมือควบคุม 34 รายการ

## 2. ขั้นตอนการติดตั้งและเริ่มต้นใช้งาน

### ขั้นตอนที่ 1: ลงทะเบียน Native Messaging (ทำครั้งแรกเพียงครั้งเดียว)
เปิด PowerShell หรือ Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```powershell
python bridge/register.py
```

### ขั้นตอนที่ 2: ติดตั้ง Extension ลงบนเบราว์เซอร์
1. เปิด **Google Chrome** หรือ **Microsoft Edge**
2. ไปที่หน้าจัดการส่วนขยาย:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. เปิดสวิตช์ **โหมดนักพัฒนา (Developer mode)** ที่มุมขวาบน
4. กดปุ่ม **โหลดส่วนขยายที่คลายแพ็กไว้ (Load unpacked)**
5. เลือกโฟลเดอร์ `zxscript-extension` จากโฟลเดอร์โปรเจกต์นี้

### ขั้นตอนที่ 3: เปิดใช้งาน MCP Server ใน Roblox Studio
1. เปิดโปรแกรม **Roblox Studio** และเปิดแมพของคุณ (ต้องเปิด Place ค้างไว้)
2. บนแถบเครื่องมือด้านบน กดปุ่ม **Assistant AI**
3. ที่มุมขวาบนของหน้าต่าง Assistant กดปุ่ม **`...` (จุดสามจุด)** แล้วเลือก **Manage MCP Servers**
4. ติ๊กเปิดตัวเลือก **Enable Studio as MCP Server**

### ขั้นตอนที่ 4: เปิดใช้งาน Bridge
เลือกวิธีใดวิธีหนึ่งต่อไปนี้:
- **วิธีที่ 1 (ผ่าน Extension Popup - แนะนำ):** คลิกไอคอน ZXScript บนแถบเบราว์เซอร์ แล้วกดปุ่ม **เปิดใช้งานทันที** ตัวโปรแกรมจะทำงานในเบื้องหลังทันทีพร้อมแสดง Log ภายในหน้าต่าง
- **วิธีที่ 2 (ผ่านไฟล์สคริปต์เดิม):** ดับเบิลคลิกไฟล์ `start.bat` ในโฟลเดอร์โปรเจกต์

## 3. ขั้นตอนการสั่งงาน AI บนหน้าเว็บ

1. เข้าเว็บ AI ที่ต้องการใช้งาน เช่น **[chat.deepseek.com](https://chat.deepseek.com/)** (แนะนำ), Claude, หรือ ChatGPT
2. สังเกตแถบ **ZXScript Dynamic Island** ด้านบนของหน้าจอ:
   - **จุดสีเขียว:** เชื่อมต่อสำเร็จ (Bridge ออนไลน์ และ Studio เปิดแมพพร้อม)
   - **จุดสีเหลือง:** Bridge เปิดอยู่ แต่ยังไม่ได้เปิดแมพใน Studio หรือยังไม่เปิด MCP
   - **จุดสีเทา:** Bridge ยังไม่ได้เริ่มทำงาน
3. เมื่อสถานะแสดงจุดสีเขียว ให้กดปุ่ม **เริ่มทำงาน** บนแถบ ZXScript
4. ระบบจะส่ง Prompt เริ่มต้นและตรวจสอบความพร้อมของเครื่องมือทั้ง 34 รายการ จากนั้นสามารถเริ่มพิมพ์สั่งงานได้ทันที

## 4. กฎเหล็กในการสั่งงานเพื่อให้ได้ผลลัพธ์ที่ถูกต้อง

### กฎข้อที่ 1: สั่งทีละ 1 ระบบย่อย
ห้ามสั่งงานรวมทั้งเกมในคำสั่งเดียว (เช่น "สร้างเกมต่อสู้เต็มระบบให้เสร็จทันที") เพราะจะทำให้เกิดการรันคำสั่งวนซ้ำต่อเนื่องมากเกินไป ควรแบ่งงานออกเป็นระบบย่อยทีละส่วน เช่น ระบบบันทึกข้อมูล, ระบบอาวุธ, หรือระบบอินเทอร์เฟซ

### กฎข้อที่ 2: ให้ AI สำรวจโครงสร้างเกมก่อนเสมอ
กำชับ AI ให้ใช้คำสั่ง `search_game_tree` หรือ `inspect_instance` ก่อนเริ่มเขียนหรือแก้ไขสคริปต์ เพื่อให้ AI ทราบตำแหน่งของ Instance ที่แท้จริง และไม่สร้างโฟลเดอร์ซ้ำซ้อน

### กฎข้อที่ 3: ใช้ปุ่มหยุดฉุกเฉินเมื่อต้องการแก้ไขคำสั่ง
หาก AI ทำงานผิดพลาดหรือไม่ตรงตามที่ต้องการ สามารถกดปุ่ม **หยุด** บนแถบควบคุมลอยตัวได้ทันทีเพื่อยกเลิกการทำงานรอบนั้นอย่างปลอดภัย

## 5. ตัวอย่างชุดคำสั่ง Prompt แนะนำ

### ตัวอย่าง: สำรวจโครงสร้างแมพก่อนทำงาน
```text
สำรวจโครงสร้าง Workspace และ ServerScriptService โดยใช้ search_game_tree แล้วสรุปสั้นๆ ว่ามีโมเดลหรือสคริปต์อะไรอยู่บ้าง
```

### ตัวอย่าง: สร้างระบบ Leaderstats
```text
สร้าง Script ชื่อ LeaderstatsHandler ใน ServerScriptService เพื่อสร้างโฟลเดอร์ leaderstats ให้กับผู้เล่นทุกคนเมื่อเข้าเกม พร้อมค่า Coins และ Level เริ่มต้นที่ 0 เมื่อเสร็จแล้วให้หยุดรอ
```

### ตัวอย่าง: สร้าง Part พร้อมคุณสมบัติ
```text
สร้าง Part ขนาด 10, 1, 10 ไว้ที่จุดกึ่งกลาง CFrame.new(0, 5, 0) ตั้งค่า Anchored เป็น true และเปลี่ยนสีเป็น BrickColor.new("Bright blue")
```
